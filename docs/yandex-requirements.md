# Требования Яндекс Игр — зафиксированный ресёрч

> Источник: официальная документация Yandex Games SDK, получено 2026-07-17.
> Чтобы не ресёрчить заново. При сомнении — свериться с первоисточником (ссылки внизу).

## 1. Ориентация экрана

- Разработчик выбирает поддерживаемую ориентацию при заполнении черновика: **Portrait** / **Landscape** / **Any** (если игра корректно работает в обеих).
- **Если игра поддерживает только одну ориентацию — Яндекс сам покажет пользователю подсказку «поверни устройство»** в другой ориентации. Свою «rotate»-заглушку делать не нужно.
- **Решение проекта: landscape-only.** Игровое поле 960×540 (16:9). Портретную раскладку не делаем — платформа сама попросит повернуть телефон.
- Для мобильных: **прогресс не должен теряться при смене ориентации** устройства.

## 2. Адаптивность / респонсив (обязательно к модерации)

- Визуальные элементы **не искажаются и не растягиваются непропорционально** при смене ориентации и/или размера доступной области.
- Игра **корректно рендерится при ресайзе окна**: активная область не выходит за пределы экрана, элементы не обрезаются.
- Активная область **растягивается вертикально/горизонтально под доступное место** (не считая sticky-баннеров).
- **Длинная сторона активной области ≤ 2× короткой.** (16:9 = 1.78× — проходит.)
- Браузерные скроллбары отключены; внутренний скролл допускается.
- Внутренние элементы и тексты **не перекрывают** друг друга.
- **Нет визуальных артефактов** при ресайзе окна.

## 3. Управление и мобильные нюансы

- Полностью **жестовое управление** (можно добавить акселерометр).
- **Размеры кнопок/элементов/графики** адаптированы так, чтобы **нельзя было случайно промахнуться** пальцем и всё было легко доступно.
- **Long-tap не должен вызывать** системное выделение / контекстное меню.
- **Полноэкранный режим** при запуске и в игре.
- Если есть ввод текста (никнейм и т.п.) — клавиатура появляется автоматически при фокусе.

## 4. Прочее (техническое)

- Минимальная длительность геймплея: **10+ минут**.
- Лимит размера: **100 MB** в распакованном виде.

## 5. Ассеты для публикации (черновик игры)

| Ассет | Размер | Формат | Обязательный |
|---|---|---|---|
| Иконка | 512×512 | PNG | да |
| Maskable-иконка | 512×512 (круглая safe-зона в центре) | PNG | нет |
| Обложка (Cover) | 800×470 | PNG | да |
| Hero-изображение | 1560×520 | PNG/JPG | нет |
| Скриншоты | 1280–2560 по длинной стороне; landscape 16:9 / portrait 9:16 | JPEG / 24-bit PNG | ≥ 2 на платформу |
| Вертикальное видео | 9:16, высота ≥ 400, ≤ 28 сек, ≤ 100 MB | MP4 | нет |
| Горизонтальное видео | 16:9, высота ≥ 400, ≤ 28 сек, ≤ 100 MB | MP4 | нет |
| Рекламные видео (до 20) | верт. мин 720×1280 / реком. 1080×1920; гор. мин 1280×720 / реком. 1920×1080 | MP4 | нет |

> Для landscape-only проекта скриншоты — только landscape 16:9.
