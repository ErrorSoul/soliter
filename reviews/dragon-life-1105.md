# Исходные слоты и живые драконы — 2026-11-05

## Изменения

- Tableau: исходные три головы и пунктирная рамка `assets/cards/slot_tableau.png`.
  Генератор сохраняет рисунок, усиливая исходную прозрачность в 2.2 раза,
  и создаёт активный `assets/vivid/slots/slot_tableau.png`. Исходный PNG не менялся.
- Основания: вместо треугольника подпись **2 → 10**, без намёка на знак масти.
  Исходные foundation PNG тоже содержали треугольник, поэтому просто вернуть их
  означало бы сохранить неоднозначность.
- `build-vivid.py`: 18 кадров на каждого из трёх исходных драконов (54 всего).
  Поворот головы до 3.5°, мягкое дыхание/выдох. Номер и внешняя рамка неподвижны:
  соответствующие области каждого PNG побайтно сравнены с обычной картой.
- `dragon_motion.lua`: первый цикл после 12–28 с игрового времени, следующие
  через 18–32 с покоя; анимация 2.4 с. Hover запускает её с cooldown 7 с.
  Индивидуальная фаза из идентификатора карты, без math.random и влияния на раздачу.
- Движение только у открытого дракона; прерывается при захвате, учебной подсветке,
  закрытии другой картой и сборе. Hover поддержан в tableau и свободной ячейке;
  собранная/заблокированная ячейка не реагирует. На touch работает редкий idle.

## Проверка на Steam Deck

По просьбе владельца местные браузеры остановлены; итоговые проверки перенесены
на SSH-host `steamdeck`. В CLAUDE.md записано выполнять тяжёлые проверки там,
по одному браузеру за раз.

- Стенд `/tmp/shenzhen-check-1105`, Linux 6.11.11-valve24-2-neptune,
  Python 3.13.1, Playwright 1.64.1, Pillow 13.0.0, Chromium headless shell 1248.
- Передана готовая свежая debug HTML5-сборка
  `/private/tmp/shenzhen-dragon-life-1105-slots/ShenzenSolitare` и тестовые исходники.
  Сборка сделана ранее на Mac; тесты ниже выполнены на Steam Deck.
- **Lua 284/284 PASS** на Steam Deck.
- **4 итоговых браузерных прогона PASS**, 0 fatal / 0 failed expectations:
  `dragonlife` 1280×800; `dragonlife` touch 844×390 DPR3;
  `tutorialfree` 1280×800; `pickupfx` 1280×800.
- `dragonlife`: реальные изменения пикселей головы при hover и без ввода,
  неподвижный номер, возврат к исходному рисунку, перенос ожившей карты в ячейку.
- Исходные два параллельных dragonlife не успели увидеть idle за 36 с.
  Программный SwiftShader и захват DPR3 на деке заметно замедляют отрисовку.
  В стенде лимит ожидания увеличен до 120 с; проверка реального изменения пикселей
  сохранена. При последовательном прогоне idle обнаружен за 29.1 с (desktop)
  и 44.4 с (mobile). Игровые интервалы дополнительно ограничены Lua-тестом.
  Начальные неудачи сохранены отдельно в `deck-initial-failures.json`.
- Между обычным и анимированным atlas-регионами на DPR3 встречалась разница
  округления одного канала на 1/255. Оракул неподвижного номера требует средней
  разницы <0.1/255; оракул движения головы — >0.6/255. Исходные PNG индекса идентичны.
- Это headless-проверки на железе Steam Deck с программным рендерером и
  эмуляцией touch, не ручная игра на экране/геймпаде и не замер FPS native GPU.
  Release в этом изменении не проверялся. `git diff --check` PASS.
